# Git Conventions

## Commits

- Conventional Commits: `feat: add endpoint`, `fix: handle null response`
- Optional scope names the affected component/module: `feat(auth): add endpoint`
- Other types as needed: `docs:`, `chore:`, `refactor:`, `test:`, `perf:`, `style:`
- Use the `/commit` skill when creating git commits or suggesting commit messages

## Branches

- Branch naming: `feat/description-of-task`, `fix/description-of-task`
- A short, kebab-case description after the type prefix
